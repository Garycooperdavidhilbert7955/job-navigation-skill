# 循证个人决策顾问

> 不再让AI给你泛泛而谈的建议。把最新证据、可靠模型和你的真实情况，转化为可以立即执行的决定。

[English](README.md) · [Skill源码](skills/evidence-based-personal-advisor/SKILL.md) · [参与贡献](CONTRIBUTING.md)

**循证个人决策顾问**是一套面向Codex的开源Skill，专注于职业、教育和个人成长决策。Codex会研究最新来源，将证据与你提供的事实和限制进行对照，再给出有优先级的行动方案。

特别适合：职业方向、岗位趋势、JD抽样、简历差距、技能规划、职业转型和教育选择。

## 你会得到什么？

```text
事实｜高可信度：近期公司官网JD反复要求SQL和漏斗分析。
限制：一个招聘平台无法完整访问，因此样本只能用于方向判断。
你的证据：学过SQL，但缺少可查看的业务分析作品（U/B级）。
立即做：发布一个SQL+看板案例；完成20次定向投递后复盘转化率。
```

目标不是生成更长的回答，而是让你看清：**证据支持什么、还有什么不确定、与你有什么关系、下一步先做什么。**

## 它解决什么问题？

普通AI建议常有三个问题：太通用、信息过时、语气过度确定。这套Skill提供了明确约束：

- **信息要新：**优先官方和一手来源，并标注研究截止日期；
- **结论有边界：**区分事实、推断、预测和建议；
- **建议适合你：**结合目标、资源、限制和机会成本；
- **模型不堆砌：**只使用1–3个能改变决策的模型；
- **控制Token：**支持quick、standard和deep三档研究；
- **简历不造假：**去重招聘广告，并按证据强度评估候选人经历。

## 适合哪些用户？

- 正在选择岗位、准备求职的学生和应届生；
- 想转行但不知道如何验证方向的职场人；
- 想用近期JD检查简历和技能缺口的求职者；
- 正在比较课程、教育或个人成长方案的人；
- 不满足于“努力提升自己”等空泛建议的人。

不适合简单事实查询、无证据的简历包装、医学诊断，或替代专业法律、医疗和财务意见。

## 工作逻辑

1. **理解问题：**明确目标、现状、限制和成功标准；
2. **确定范围：**选择快速、标准或深度研究；
3. **分层检索：**先查官方与一手来源，再补充综述和市场信号；
4. **评估证据：**检查权威性、直接性、时效、方法、独立性和一致性；
5. **选择模型：**只保留能改变行动方案的商业、学术或实践模型；
6. **结合个人：**将市场证据与你的真实经历和约束对照；
7. **确定优先级：**分为立即做、低成本验证、下一步构建和暂缓；
8. **持续复盘：**设置指标和复盘日期。

职业分析会进一步建立：

`岗位要求 → 市场需求带 → 候选人证据 → 证据等级 → 缺口类型 → 下一步行动`

候选人证据从**A级（外部验证）**到**U级（无法支持）**分级，避免把团队成果、模拟测算或计划功能写成个人真实业绩。

## 安装

需要安装**Codex**和**Python 3.9+**。

在GitHub页面点击 **Code → Download ZIP**，或复制 **Code** 菜单里的地址进行克隆。进入解压或克隆后的仓库目录，再运行：

```bash
cd evidence-based-personal-advisor
python3 scripts/install.py
```

安装器会将Skill复制到`${CODEX_HOME:-~/.codex}/skills/evidence-based-personal-advisor`，如果目标已经存在则停止，不会直接覆盖。

安装后的下一个Codex回合即可使用。

## 使用示例

```text
使用 $evidence-based-personal-advisor：

我是数据科学应届生，目标是深圳AI产品岗位。
请研究最近六个月的行业和JD趋势，结合我的简历找出证据差距，
给出30/60/90天计划，并区分事实、推断和建议，说明检索限制。
```

安装后也可以自然提问：

```text
请结合最新证据和我的个人限制，帮我比较这几个职业方向。
```

### 三种研究档位

| 档位 | 适用情况 | 典型范围 |
|---|---|---|
| `quick` | 快速了解、低风险方向判断 | 4–8个来源、1–2个模型 |
| `standard` | 大部分职业与个人决策 | 8–15个来源、1–3个模型 |
| `deep` | 系统比较或重大决策 | 更广来源、矛盾分析、明确局限 |

## 信任边界

- Skill可以提高研究纪律，但不能保证检索穷尽或来源本身完全正确；
- 招聘网站可能存在重复、过期、个性化和访问限制；
- 分析模型用于组织思考，不等于实证证据；
- 上传简历或个人材料前，请删除不必要的敏感信息；
- 高风险决策仍应在必要时咨询合格专业人士。
