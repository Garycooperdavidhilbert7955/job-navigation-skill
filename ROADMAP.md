# Roadmap

The next milestone is evidence, not more frameworks.

## Now — public beta

- Make installation and first use understandable without prior Skill knowledge.
- Collect at least 10 paired baseline/Skill tasks across the existing evaluation scenarios.
- Recruit at least 10 students, recent graduates, and career changers for opt-in usability feedback.
- Publish aggregate cost, failure, and null-result data without resumes, prompts, or personal records.

## Next — behavioral validation

- Add a reproducible runner that records model, tool access, research cutoff, and Skill version.
- Measure citation support, evidence calibration, personalization, actionability, and cognitive load.
- Publish several redacted examples, including one sparse-evidence or failed-research case.
- Revise the Skill from observed failures rather than adding theory by default.

## Later — scope expansion

- Build dedicated education-decision and career-change modules only after the career beta is stable.
- Test additional languages and geographies with appropriate source hierarchies.
- Explore compatible packaging for other agent-skill-standard clients without weakening the Codex experience.

## Not planned

- Automatic job applications or messages.
- Hosted collection of resumes or personal histories.
- Guaranteed outcomes, exhaustive web coverage, or universal decision scores.
- Framework accumulation without evidence that it changes decisions.
