# Tool access and job-source policy

Read this file before using web search, browsers, connectors, MCP servers, or user-authenticated job platforms. Tool access comes from the active agent environment, not from this Skill.

## Availability gate

1. Inspect the tools actually exposed in the current environment.
2. Use native search or browser access when available.
3. Use a connector or MCP tool only when it is installed, authorized, relevant, and permitted for the requested data.
4. Refer to an MCP tool by its fully qualified server and tool name. Never invent a server, tool, login state, or successful request.
5. If no suitable tool is available, ask for exported links or JD text, or narrow the task and disclose the limitation.

Do not make a specific MCP, crawler, browser extension, or paid data provider a hidden requirement. Never bypass authentication, access controls, robots rules, rate limits, or website terms.

## Source routing

Use the smallest sufficient route:

1. First-party employer career pages for live requirements and posting details.
2. Official statistics, occupational taxonomies, and method-disclosed industry reports for broader market claims.
3. Accessible job-board listings for current hiring signals and wording.
4. Search-result snippets only as discovery leads; verify pivotal details on the destination page when possible.
5. User-provided JD exports or text when a requested platform is inaccessible.

BOSS直聘, LinkedIn, Indeed, and similar platforms are requested source channels, not mandatory equal quotas. Do not claim that a platform was sampled when only inaccessible results, stale snippets, or unverified reposts were found.

## Privacy boundary

- Search with non-identifying role, skill, geography, seniority, and date terms.
- Do not send a resume, name, phone number, email, account identifier, private URL, or confidential employer information to search tools or third-party connectors.
- Use user-authenticated sessions only for the task the user requested. Do not submit applications, contact employers, or change account data unless separately and explicitly authorized.
- Prefer local comparison of supplied resume material after market evidence is collected.

## Failure record

For each requested source channel, record `usable`, `partial`, `blocked`, or `not available`. Report the query or access date, usable item count, material exclusions, authentication or tool limits, and any substitution. Lower confidence or narrow the claim when missing access could change the decision.
