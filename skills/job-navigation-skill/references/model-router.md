# Model router

Frameworks organize reasoning; evidence supports claims. Select 1–3 complementary models whose outputs could change the action plan.

| Need | Preferred model | Use it to | Avoid when |
|---|---|---|---|
| Clarify a messy problem | Issue tree / MECE hypotheses | Split the decision into testable questions | The problem is already narrow |
| Understand external change | PESTLE | Scan political, economic, social, technological, legal, environmental forces | Only individual fit matters |
| Analyze industry structure | Porter's Five Forces | Examine bargaining power, rivalry, entry, substitutes | Predicting an individual's hiring odds |
| Compare internal and external fit | SWOT/TOWS | Convert strengths/limits and opportunities/threats into options | Used without evidence or prioritization |
| Understand user/customer demand | Jobs to Be Done | Identify functional, social, and emotional progress sought | Treating interview anecdotes as market size |
| Choose among options | Multi-criteria decision analysis | Weight criteria and run sensitivity checks | Weights are hidden or fabricated |
| Decide under uncertainty | Expected value + scenario analysis | Compare upside, downside, probability, reversibility | Probabilities are presented as precise facts |
| Plan learning | Deliberate practice + feedback loops | Define subskills, practice, feedback, measurement | Recommending courses without practice artifacts |
| Change behavior | COM-B | Diagnose capability, opportunity, and motivation barriers | The bottleneck is primarily structural policy |
| Career choice/development | Person–environment fit + SCCT | Connect interests, efficacy, supports, barriers, and outcomes | Labeling personality as destiny |
| Turn findings into action | OODA / PDCA | Run short observe-test-learn cycles | A one-time irreversible decision |
| Analyze a resume against demand | Competency matrix + evidence gap | Map requirement, market frequency, proficiency, proof, gap, action | Keyword matching alone |

## Selection rules

1. Name the decision each model informs.
2. Prefer one external lens, one personal-fit lens, and one action lens when all three are needed.
3. Remove any model that duplicates another or produces no different action.
4. State assumptions and model limitations.
5. For weighted scoring, show weights and test whether plausible weight changes alter the ranking.

## Common bundles

- Career-market scan: PESTLE (only relevant dimensions) + competency matrix + OODA.
- Career-option choice: SCCT/person–environment fit + multi-criteria decision analysis + small experiments.
- Industry-entry decision: Five Forces + SWOT/TOWS + scenario analysis.
- Skill-development plan: evidence-gap matrix + deliberate practice + PDCA.

Do not load or cite a long history of each model. Use canonical sources only when the model itself is material to the user's decision or they request academic grounding.
