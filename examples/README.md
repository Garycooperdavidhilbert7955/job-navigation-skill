# Examples

Examples demonstrate output shape, not effectiveness.

- [Early-career AI role brief](early-career-ai-role-brief.md) is fictional, abbreviated, and contains no current market claims.

Future real examples must be opt-in and redacted. Do not commit resumes, prompts, raw model outputs, contact details, employer-confidential information, or claims that cannot be audited. Include at least one access-limited or negative example so the collection does not become a showcase of successes only.
