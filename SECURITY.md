# Security and privacy

This Skill may be used with resumes, career histories, or other personal material. Share only what is necessary and remove identifiers that are not needed for the decision.

Do not commit:

- resumes or personal records;
- phone numbers, personal email addresses, IDs, or exact home addresses;
- API keys, access tokens, passwords, or private URLs;
- confidential employer or client information.

If you discover a privacy or security issue, report it privately to the repository owner through GitHub's security advisory feature rather than opening a public issue.
